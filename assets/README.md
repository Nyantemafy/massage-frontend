# Assets

Ce dossier contient les ressources de l'application.

## Fichiers requis (à créer)

Pour une application Expo complète, ajoutez:

1. **icon.png** (1024x1024px)
   - Icône principale de l'application

2. **splash.png** (1284x2778px)
   - Écran de démarrage

3. **adaptive-icon.png** (1024x1024px)
   - Icône adaptative pour Android

4. **favicon.png** (48x48px ou 64x64px)
   - Favicon pour la version web

## Créer vos propres assets

Vous pouvez utiliser des outils comme:
- Figma
- Canva
- Adobe Illustrator
- GIMP (gratuit)

## Assets temporaires

Pour tester l'application sans créer d'images personnalisées:
- Expo utilise des images par défaut
- L'application fonctionnera normalement sans ces fichiers
